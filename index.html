Privacy Policy

Expense Manager

Compose R.A Studio developed Expense Manager as a personal finance management application designed to help users record and track their income, expenses, budgets, and accounts simply and securely

The application works 100% locally on the user's device. It does not have its own server (backend), does not require creating an account, does not ask for user registration, and does not use any authentication method, such as logging in with Google or any other provider

Information privacy and security are a priority for Compose R.A Studio. This Privacy Policy explains what information is collected, how it is used, and what the user's rights are

Information Storage

All financial information created by the user, including, but not limited to:

  • Income
  • Expenses
  • Budgets
  • Categories
  • Accounts and transfers between accounts

is stored exclusively on the user's device. Compose R.A Studio does not collect, store, process, or have access to this financial information

The data remains under the exclusive control of the user, unless they decide to export it or make a backup using the features available in the application

No Personal Data is Collected

Expense Manager:

  • Does not require creating an account
  • Does not ask for name, email, or phone number
  • Does not use authentication through Google, Facebook, or other services
  • Does not sync information with its own servers
  • Does not sell or share users' financial information

Third-Party Services

The application uses some services provided by Google to improve the quality, stability, and performance of the application. These services may collect limited technical information according to their own privacy policies

Google Play Services

Google Play Services provide essential components for the proper functioning of certain Android system features and ensure compatibility with services offered by Google

Firebase Analytics

Firebase Analytics is used exclusively for analytical purposes to understand how the application is used, identify which features are most used, and continuously improve the user experience

The collected information allows:

  • Analyzing overall app usage.
  • Detecting usage trends.
  • Improving user experience.
  • Optimizing performance.
  • Prioritizing future improvements.

Firebase Analytics is not used to personally identify users or to access financial content stored in the application

Firebase Crashlytics

Firebase Crashlytics is used to collect technical information when an unexpected crash or app error occurs

Its purpose is:

  • Detecting errors
  • Analyzing the cause of crashes
  • Fixing stability issues
  • Improving the reliability of future versions

The collected information corresponds only to technical crash data and does not include financial content recorded by the user

Collected Technical Information

Google services used by the application may collect technical information such as:

  • App usage events
  • Device information
  • Operating system version
  • Device language
  • Approximate location (when provided by Google services and according to device settings)
  • Device identifiers
  • Technical identifiers
  • Crash Reports
  • Device metrics at the time of the crash
  • Session state during the error

This information is collected solely for statistical, analytical, and diagnostic purposes to improve the app's functioning. Compose R.A Studio does not use this information to personally identify users

Export and Backups

The application may offer features to export information or generate backups. These actions are initiated only by the user, and the generated files remain under their control. Compose R.A Studio does not receive a copy of these files

Biometric Authentication

Expense Manager offers an optional biometric authentication feature that allows users to protect access to the application using fingerprint authentication, depending on their device's capabilities

Biometric authentication is processed entirely by the Android operating system, using the device's secure authentication framework (BiometricPrompt). Compose R.A Studio does not collect, store, process, transmit, or access any biometric data, including fingerprints

Children's Privacy

Expense Manager is not directed to children under 13. Compose R.A Studio does not knowingly collect personally identifiable information from children

Changes to this Privacy Policy

This Privacy Policy may be updated occasionally to reflect changes in the application, the services used, or applicable legal requirements. Modifications will take effect from the date of their publication

Acceptance

By using Expense Manager, the user acknowledges having read and understood this Privacy Policy and agrees to the processing of technical information described in this document
